# Peak Summit Casino

A BepInEx multiplayer mod for PEAK that adds a gambling room at the summit with time-limited games from Gamble With Your Friends.

## Installation

1. Install BepInEx
2. Extract this mod into your `BepInEx/plugins/` folder
3. Run the game

## Features

- Multiplayer gambling room
- Time-limited games
- Integration with Gamble With Your Friends mod
